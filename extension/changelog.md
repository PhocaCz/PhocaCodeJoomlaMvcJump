# Change Log

All notable changes to "Phoca Joomla MVC Jump" are documented in this file.

## [1.0.0] - 2026-11-25

- First release.
- Four commands to jump between the tmpl layout, view, model and controller of a Joomla 4/5 component.
- Buttons in the editor title bar and the shortcuts `Ctrl+Alt+T/V/M/C`.
- Picker when a tmpl folder contains several layouts.
- Lazy activation, the extension is loaded only when one of its commands is used.
